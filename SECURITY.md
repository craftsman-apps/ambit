# Security policy

Ambit controls who may use which AI models and tools, so we treat security reports as the highest priority.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private vulnerability reporting for this repository
(Security → Report a vulnerability). Include the Ambit version, what you did, and what you expected.

We acknowledge reports within 3 working days and aim to ship a fix for confirmed high or critical issues within 30 days.

## Supported versions

Ambit is pre-1.0 (`v1alpha1` APIs). Only the latest release receives fixes.
