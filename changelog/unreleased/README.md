# Unreleased changes

Each pull request adds one file here for the changes that users can see. Name it after the branch, without the
`pueding/` prefix: `ci-image-e2e-split.md` for the branch `pueding/ci-image-e2e-split`.

The file holds the bullet lines exactly as they will appear in `CHANGELOG.md`, in plain English. Do not add a heading.

At a release, `node site/scripts/changelog-assemble.mjs <version> <YYYY-MM-DD>` copies the lines of all files here
(in file name order) into a new version section of `CHANGELOG.md` and deletes the files. This README stays.
