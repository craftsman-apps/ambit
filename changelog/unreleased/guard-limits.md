- Masking: ambit-guard now accepts tool results larger than 4 MiB (the gRPC limit is 32 MiB). With the default memory limit, results up to 10 MiB were masked in a test; larger ones can make the guard run out of memory (see Masking in Concepts). With Presidio, it sends a result to the analyzer in a few large calls instead of two calls per string, and it replaces the findings itself. The anonymizer is no longer called. The new value `protection.presidio.timeout` (default 10 s) limits all analyzer calls of one result.
- Docs: Presidio replaces the built-in masks, it does not add to them. See Masking in Concepts.
