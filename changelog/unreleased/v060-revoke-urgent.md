- Removing access no longer waits for a rules change that is already in progress. When you delete an `AccessRule`, or take a group, a person, a model, a server or a tool out of one, while the controller is still waiting for agentgateway to apply an earlier change, the controller stops that wait and writes the removal at once (a new change that has the same effect on grants as before). Before, the removal waited for the earlier change, about 5 s with the default settings and up to 2 times `access.activationTimeout` when agentgateway did not accept a step. A new or wider rule keeps its order and its waits. Audit-only mode is not changed.
